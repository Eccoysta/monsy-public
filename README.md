Monsy

A SwiftUI habit tracking starter built around Monstera plants, streaks, and group approvals.

What’s included
- SwiftUI app scaffold
- 16 Monstera growth levels plus dying states
- Daily photo upload UI
- Group approval flow
- Apple Sign In starter flow
- Supabase backend configuration placeholder
- Xcode project package ready to open in Xcode
- project.yml for XcodeGen if you want to regenerate the project later

Open in Xcode
- Clone the repo
- Open Monsy.xcodeproj
- Build and run

If you want to regenerate the project later, install XcodeGen and run it from the repo root using project.yml.
